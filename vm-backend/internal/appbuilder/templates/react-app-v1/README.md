# VentureMate Generated App

This React + TypeScript + Vite project was generated by VentureMate AI Studio.

## Local development

```bash
npm ci
npm run lint
npm run build
npm run dev
```

The project contains no VentureMate server credentials. Managed data access is scoped to this generated project through `src/runtime/project.ts`. Rotate the runtime key from VentureMate before sharing source publicly.

## Environment

Copy `.env.example` to `.env.local` only when you need to override the managed-runtime base URL. Never commit secret values.
